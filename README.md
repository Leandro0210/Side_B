# SIDE B — auditoría ética de recomendaciones musicales

Prototipo académico de recomendación musical con Gradio para medir y mitigar sesgos de popularidad y estudiar la exposición de artistas.

**Importante:** las calificaciones simuladas no son evidencia de personas reales. El sistema se ejecuta localmente; no publique claves ni evaluaciones individuales.

La documentación y el código de la siguiente iteración se incorporan mediante Pull Request.
