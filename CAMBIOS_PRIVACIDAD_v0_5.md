# SIDE B v0.5 — Privacidad y explicabilidad

- Se integró la actualización v0.4 de supervisión y seguridad a partir del paquete previamente generado.
- El ranking individual ahora expone sus dos contribuciones verificables (similitud de etiquetas y popularidad).
- Se muestran etiquetas coincidentes, procedencia de metadatos de grabación ilustrativa, tamaño del conjunto elegible y estado del tope.
- Se creó `docs/PRIVACIDAD_EXPLICABILIDAD.md` para explicar minimización, retención, limitaciones y exclusión de respuestas personales del repositorio público.
- Se agregó GitHub Actions para ejecutar pruebas automáticamente.
- Se reforzó `.gitignore` para prevenir publicación accidental de datos privados y sesiones locales.
- Los resultados científicos originales y el dataset fuente permanecen intactos.

**Limitaciones**: demostración académica local; no verificación de preferencias a gran escala; las evaluaciones sintéticas no son testimonios humanos.
